# Sharing project photos with work orders — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A share button on project photos puts them, read-only, in the internal photo strip of every work order of that project, stored in a generic `shares` table with an access level.

**Architecture:** One `shares` row per shared record, keyed on the record it was shared from (two morphs). Work orders read it through `project_id` with a `belongsToMany` over `shares`. An action writes or removes the row and raises `ImageShareChanged` on the project.

**Tech Stack:** Laravel 12, Inertia, Vue 3, MySQL.

**Spec:** `docs/superpowers/specs/2026-11-16-shares-design.md`

## Global Constraints

- PHP variables snake_case; no inline comments; `$a . ' b'` concatenation; `!$foo` with no space.
- Tenant migration in `database/migrations/tenant/`.
- Authorization in Form Request `authorize()` through a policy method; validation in `rules()` only.
- FQCNs in `_type` columns, no morph map.
- Toggle in the UI: pressing share again unshares, no separate clear button.
- No tests (project rule: only when asked). No commits without the user's sign-off.
- Pint per edited file (never a directory), eslint per edited file.
- Don't touch the files another session has open in the worktree (Tray work, `BaseSignal`, `Signal`, `RecordActivity`, `Activity`, `User`, `TicketPolicy`, `AppServiceProvider`, `ServiceOrderController` is already modified — edit only the `show()` eager-load line there).

## Review Focus

- A photo whose project is deleted, or a work order without a project: no shared strip, no error.
- A photo deleted on the project while shared: the share row goes with it; work orders stop showing it.
- Two open project screens: sending `shared=true` twice leaves one row (unique index + `firstOrCreate`).
- Sharing a photo that hangs on a work order or machine via a hand-made request: refused with a readable message.
- The work order's own internal strip must not offer delete/annotate/favourite on a shared photo, on desktop or the phone tap menu.

**Interfaces — Produces:**
- `shares`: `id`, `shareable_type` + `shareable_id` (no own index: the unique index starts with them), `morphs('source')`, `access` string(20) default `'view'`, `foreignIdFor(User::class)->nullable()->constrained()->nullOnDelete()`, timestamps, `unique([shareable_type, shareable_id, source_type, source_id], 'shares_shareable_source_unique')`.
- `enum ShareAccess: string { View = 'view'; Edit = 'edit'; Manage = 'manage'; }` with `allows(ShareAccess $needed): bool` over a private `rank()`.
- `Share extends Pivot` (`$table = 'shares'`, `$incrementing = true`): fillable `shareable_type, shareable_id, source_type, source_id, access, user_id`; `access` cast to `ShareAccess`; `shareable(): MorphTo`, `source(): MorphTo`, `user(): BelongsTo`; `grants(ShareAccess $access): bool`; `static canShareFrom(?Model $source): bool` (true for `Project`).
- `Shareable` trait: `shares(): MorphMany` (`Share`, `'shareable'`), `bootShareable()` deleting its shares on `deleted`. `@mixin Model` annotation.

**Interfaces:**
- Consumes: `Share`, `ShareAccess`, `Share::canShareFrom()`, `Image::attachedRecord()`.
- Produces: `ShareRecordAction::execute(Model $shareable, ?Model $source, bool $shared): void` — idempotent; dispatches only on change; refuses a source `canShareFrom()` rejects. `ImageShareChanged(Model $source, Image $image, bool $shared)` key `image.share_changed`, category `image`, subject the project, description `Afbeelding "naam" gedeeld met de werkbonnen` / `… niet meer gedeeld met de werkbonnen`, `changes()` with the field `shared` before and after, metadata `thumbnail_path` + `thumbnail_image_id`.
- Request rules: `'shared' => 'required|boolean'`. Controller passes `$image->attachedRecord()` as the source; the action refuses with `Refusal('Delen kan alleen vanaf een project, met de werkbonnen eronder.')`. JSON → `{shared: bool}`; otherwise back with success flash.
