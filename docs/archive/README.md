# Build notes

Plans and design notes written while features were being built, kept because
they say *why* something was decided. They are **not maintained**: where one of
these and the code disagree, the code is right.

- `plans/` — what was going to be built, task by task
- `specs/` — the design that came before the plan

The one still worth reading is
[`plans/2026-06-09-multi-database-tenancy.md`](plans/2026-06-09-multi-database-tenancy.md),
the original tenancy plan. The short version of what it built is
[development/multi-tenancy.md](../development/multi-tenancy.md).
